# SL Sadeepa Tec - Personal Portfolio Website 👨‍💻

Welcome to the official repository for **SL Sadeepa Tec**. This is a multi-page personal portfolio website designed to showcase my biography, skills, creative work, and YouTube content.

## 📖 Overview

This project is a static website built to establish an online presence. It serves as a hub for my social media channels, provides a way for visitors to contact me, and demonstrates my frontend web development skills using HTML5, CSS3, and JavaScript.

## ✨ Features

*   **Multi-Page Navigation:** Easy navigation between Home, About Me, My Work, and Contact pages.
*   **Interactive Slideshow:** A fully functional JavaScript image carousel on the homepage.
*   **Live Analog Clock:** A real-time clock rendered using HTML5 Canvas and JavaScript.
*   **Skill Bars:** Visual representation of proficiency in HTML, CSS, JS, and PHP.
*   **Social Media Integration:** Direct links to YouTube, WhatsApp, Telegram, and Instagram.
*   **Interactive Elements:**
    *   Popup Alert messages.
    *   Popup Login/Contact forms.
    *   Copy-to-clipboard functionality for code snippets.
*   **Responsive Design:** specific styles adapted for different screen sizes.

## 🛠️ Technologies Used

*   **HTML5:** For the structure of the web pages.
*   **CSS3:** For styling, layout, and animations (includes `style.css`, `a.css`, and `main.css`).
*   **JavaScript:** For logic, time/date functions, slideshows, and event handling.
